minneola 1.4 - browser
features:
- start keyboard
- source code viewer
- terminal
- CTRL + '+' for zoom
- CTRL + '-' for unzoom
- CTRL + '0' for reset zoom
- CTRL + 'l' for adress focus
- CTRL + '<-' for back
- CTRL + '->' for forward
- drag and drop files and text
- auto-hide
- page-save
- file download
- source code available
download: https://sites.google.com/view/honeybell/minneola-1-4
