## minneola 1.4 - browser
## features:
* start keyboard
* source code viewer
* terminal
* CTRL + '+' for zoom
* CTRL + '-' for unzoom
* CTRL + '0' for reset zoom
* CTRL + 'l' for adress focus
* CTRL + '<-' for back
* CTRL + '->' for forward
* auto hidden address bar
* page saver
* file download
* source code available
> [!IMPORTANT]
> compilation: python minneola.py
> [!WARNING]
> the browser or its features can go wrong !!!
