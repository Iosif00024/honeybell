## features:
* **start keyboard with interesting logic**
* **ad blocker included ([adblock.py](https://github.com/Iosif00024/honeybell-browser/blob/main/minneola/adblock.py))**
* **https-first feature**
* **source code view**
* **page saver**
* **files download**
* **reader view**
* **bookmarks**
* **zoom**
* **page searcher**
* **fullscreen**
* **print**
* **user agent ([webview.py](https://github.com/Iosif00024/honeybell-browser/blob/main/minneola/webview.py))**
* **hardware acceleration**
* **console with logs**
